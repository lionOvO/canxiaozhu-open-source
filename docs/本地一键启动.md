# 本地一键启动

`backend/.env` 配置 `EMBEDDING_PROVIDER=local` 时，PC/手机端脚本会先启动或复用已有 Ollama BGE-M3（端口 11434），后台运行，不额外打开终端，也不会重新下载模型。详见 [本地向量检索](本地向量检索.md)。一键停止仅处理本项目的前后端，保留共享的 Ollama 服务。

双击项目根目录的 `启动餐小助-pc端.bat` 或 `启动餐小助-手机端.bat`。启动提示窗口会在检查完成后关闭，前后端在后台运行，不再各自打开终端。

| 服务 | 访问地址 |
| --- | --- |
| PC 端 | http://localhost:5173/dashboard |
| 手机端 | http://localhost:5174/dashboard |
| 后端健康检查 | http://127.0.0.1:3000/api/v2/health |

PC 端和手机端可以同时启动，共享一个后端。重复点击会复用本项目已有服务；同时点击会排队检查，避免重复启动。端口被其他程序占用时会显示错误并保留提示窗口，固定端口不会自动切换。

支持识别通过 IDE、命令行启动的本项目服务，包括在 `backend` 中运行的 `node --import tsx src/server.ts`，以及在对应前端目录中运行的 `node node_modules/vite/bin/vite.js`。相对路径启动时会核验进程实际工作目录；读取失败或目录不匹配时仍会拒绝复用。其他端口上的前端预览（如 5183）不会阻碍在 5173 启动 PC 端。已识别的相对路径进程也纳入一键停止范围。

手机访问时，手机和电脑需连接同一局域网。启动时会显示局域网地址，同时写入 `.tmp/canteen-dev/phone-urls.txt`，可打开该文件查看。

双击 `停止餐小助.bat` 停止本目录的前后端开发服务，包括旧版脚本创建的服务终端。关闭启动提示窗口不会停止后台服务。

日志保存在 `.tmp/canteen-dev/`：`backend.log`、`pc.log`、`phone.log` 为输出日志，对应的 `*.error.log` 为错误日志。每次重新启动对应服务会覆盖它的旧日志；复用运行中的服务不会覆盖日志。

排错时可在 PowerShell 中执行：

```powershell
# 实时查看后端输出，Ctrl+C 退出查看，不影响后台服务
Get-Content -LiteralPath .tmp/canteen-dev/backend.log -Tail 50 -Wait

# 仅检查启动条件，不创建进程
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-canteen-helper.ps1 -DryRun

# 仅预览停止范围
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\stop-canteen-helper.ps1 -DryRun
```

脚本直接通过 Node.js 启动项目已安装的 tsx / Vite，保留后端和前端的热更新。首次使用需先在对应目录安装依赖。如果未来修改 `package.json` 的 `dev` 命令（例如加入额外环境变量或预处理），需同步调整 `scripts/canteen-dev.psm1` 中的启动参数。
