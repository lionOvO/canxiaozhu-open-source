# 餐小助·商户智能经营助手：销售话术与获客手册

---

## 1. 销售总则

### 1.1 销售定位

餐小助不是卖软件，而是帮老板“省人力、省时间、省损耗、多赚钱”。销售的核心不是讲功能，而是讲“每月多赚多少钱、少亏多少钱”。

### 1.2 开场三句话原则

1. **一句话引起注意**：讲一个同类型门店的真实改变。
2. **一句话讲清价值**：每月省3000、多赚5000。
3. **一句话降低防御**：不是让你换收银系统，是帮你把现有数据算清楚。

### 1.3 客户分层切入点

| 客户类型 | 核心痛点 | 切入点 | 话术钩子 |
|----------|----------|--------|----------|
| 外卖店 | 平台扣点多、真实利润算不清、差评影响大 | 算清真实利润+差评实时预警 | “您知道昨天美团那几单，扣完点到手还有多少吗？” |
| 社区快餐店 | 老客户流失、凭经验进货、损耗高 | 留住老客户+智能采购 | “您这条街的老客户，您认识几个？” |
| 夫妻店 | 不会用电脑、时间碎片化、没人帮忙管数据 | 微信小程序+语音问答 | “您只用微信，不用学电脑，说话就能问今天赚了多少。” |
| 小型连锁（3-10家） | 多店数据分散、督导效率低、活动难统一 | 多店实时看板+统一运营 | “您现在看8家店业绩，要开几个后台？” |
| 轻食/茶饮创业者 | 新品多、毛利薄、私域弱 | 菜品盈利分析+自动化会员运营 | “您上个月的10个新品，到底哪个在亏钱？” |

## 2. SPIN话术脚本（15分钟面谈版）

### 2.1 开场（1分钟）

**目标**：建立信任，说明来意，不推销。

> 销售：王老板您好，我是餐小助的小李。我们专门帮中小餐饮老板用AI管店。今天过来不是卖您收银机，是想看看您每天算账、管客、进货这些事，能不能帮您省点时间、多赚点钱。您先忙，我坐这儿等您两分钟。

### 2.2 现状提问（Situation，3分钟）

**目标**：了解客户当前经营状态，收集信息。

| 提问 | 目的 |
|------|------|
| 您现在一天大概多少单？美团、饿了么、堂食各占多少？ | 判断规模与渠道结构 |
| 您每天花多长时间对账、看数据？ | 挖掘时间成本 |
| 您现在怎么知道昨天真实赚了多少钱？ | 挖掘利润黑盒痛点 |
| 您店里有没有会员系统？老客户怎么维护？ | 挖掘客户资产流失痛点 |
| 您每天进货是凭经验还是看数据？大概损耗多少？ | 挖掘库存损耗痛点 |
| 您遇到过差评没及时处理，影响订单的情况吗？ | 挖掘口碑管理痛点 |

**示例对话**：

> 销售：王老板，您现在一天大概多少单？
>
> 老板：大概一百多单吧，美团多，饿了么少一点，堂食也有一些。
>
> 销售：那您每天晚上对账，大概要多久？
>
> 老板：少说一个小时，有时候单子多了要对两个小时。
>
> 销售：那一个月就是三四十个小时，差不多小一个礼拜的人工了。您算过这里面如果算错了，一个月可能差多少钱吗？

### 2.3 痛点提问（Problem，4分钟）

**目标**：让客户自己说出痛点，强化痛感。

| 提问 | 对应痛点 |
|------|----------|
| 您有没有算过，美团一单扣掉平台费、优惠、包装，到手利润到底有多少？ | 真实利润黑盒 |
| 您店里有几个老客户是您叫得出名字的？平台客人离店后还能联系到他们吗？ | 客户资产流失 |
| 您上个月扔掉的菜大概值多少钱？有没有算过损耗占营业额的比例？ | 库存损耗失控 |
| 您做活动是不是经常就是“全场8折”？有没有算过引来的是不是羊毛党？ | 营销凭感觉 |
| 您排班是根据客流还是固定几个人？高峰期有没有忙不过来、闲时没事做？ | 人力调度低效 |
| 您有没有遇到过证件到期被罚款、差评没回被平台降权的情况？ | 食安合规风险 |

**示例对话**：

> 销售：王老板，您有没有算过，美团一单客人付30块，扣完平台费、满减、配送补贴，您实际到手大概多少？
>
> 老板：大概十几块吧，没细算。
>
> 销售：很多老板都算不清这个账，结果看着营业额不错，月底一算没赚钱。您上个月有没有这种感觉？
>
> 老板：有啊，有时候忙得不行，月底一算也就那样。

### 2.4 暗示提问（Implication，3分钟）

**目标**：把痛点放大，让客户意识到不改变的代价。

| 提问 | 放大后果 |
|------|----------|
| 如果每天对账花1小时，一年就是360小时，差不多一个半月，您说值多少钱？ | 时间成本 |
| 如果一个老客户一个月消费300块，一年就是3600块。您一个月流失10个老客户，一年就是3万多，您考虑过吗？ | 客户流失损失 |
| 如果损耗率从10%降到5%，按您月营业额10万算，一个月就能省5000块，这部分钱现在是不是就白白扔掉了？ | 损耗损失 |
| 如果差评没及时回，平台降权，接下来几天订单掉20%，您急不急？ | 口碑损失 |

**示例对话**：

> 销售：王老板，您刚才说每天对账一到两个小时。咱们按一个小时算，一年就是360个小时，折合一个半月。您请一个杂工一个月多少钱？
>
> 老板：四千多吧。
>
> 销售：那您这一个月半的时间，就相当于六七千块的成本。而且这还没算算错账、漏单的钱。如果有个工具每天自动把账算好，您觉得值不值？

### 2.5 需求效益提问（Need-payoff，3分钟）

**目标**：引导客户说出想要改变，并量化价值。

| 提问 | 引导方向 |
|------|----------|
| 如果每天经营日报自动推送到您微信，您一睁眼就知道昨天赚了多少，对您有没有帮助？ | 经营日报价值 |
| 如果系统自动算出明天该买什么、买多少，您进货会不会更省心？ | 智能采购价值 |
| 如果有老客户30天没来，系统提醒您发一张5块钱券，预计能拉回一半人，您愿不愿意试？ | 客户召回价值 |
| 如果一个月能帮您省3000块、多赚5000块，您觉得这钱花得值不值？ | 综合价值 |

**示例对话**：

> 销售：王老板，如果每天早上8点，您微信自动收到一条消息，告诉您昨天赚了多少钱、有没有异常、今天该注意什么，您每天能省多少时间？
>
> 老板：那起码省一个小时。
>
> 销售：一个月就是30个小时。再加上系统帮您管库存、管老客户，一个月省3000、多赚5000，您愿意试一个月吗？

### 2.6 收尾邀约（1分钟）

> 销售：王老板，我看您这店的情况特别典型。我们有个10分钟的小DEMO，不用您准备什么，我用手机给您演示一下。您看是现在方便，还是下午您不忙的时候？

## 3. 异议处理8条

### 3.1 “我店小，不需要这个”

**应对**：
> 您店小，所以每一笔利润更珍贵。我们很多客户就是夫妻店，正因为人少，才更需要AI帮忙盯数据。您不用招人，一个月99块钱，相当于请了个数字化会计。

**转化点**：小店铺更需要效率，低成本替代人工。

### 3.2 “我不会用电脑/软件太复杂”

**应对**：
> 我们的老板端就是微信小程序，您会用微信就会用。每天早上自动给您推消息，您点开看就行。想查什么直接说话，比如问“这周怎么样”，AI直接用语音回答您。

**转化点**：零学习成本，语音交互。

### 3.3 “数据安全吗？我的经营数据会不会被泄露？”

**应对**：
> 我们用的是阿里云/腾讯云，数据加密存储，手机号都是脱敏的，只有您自己能看到。而且我们是做B端服务的，数据安全是命根子，绝不会拿您的数据去做别的。

**转化点**：国内云、加密、脱敏、合规。

### 3.4 “AI不准怎么办？算错了怎么办？”

**应对**：
> AI给的是建议，不是命令。比如采购单，系统会标注置信度， confidence低的您多核对一下；最终确认还是您点。我们还会根据您的反馈越来越准，新店数据少时会有冷启动保护。

**转化点**：AI建议+人工确认，持续学习。

### 3.5 “我已有美团收银/客如云，不需要”

**应对**：
> 我们不替代您的收银系统，我们是帮您把美团、饿了么、抖音、现金这些数据汇总起来，算出一个真实利润。您的收银系统擅长收款，我们擅长帮您做经营决策。

**转化点**：互补而非替代，跨平台整合。

### 3.6 “贵不贵？一个月多少钱？”

**应对**：
> 基础版99元一个月，相当于一天3块钱，帮您省一个人每天对账的时间。专业版299元，包含智能采购、会员运营、差评回复这些。您算算，只要帮您一个月少损耗几百块菜钱，就回本了。

**转化点**：低成本高回报，ROI清晰。

### 3.7 “我试过别的软件，不好用，后来不用了”

**应对**：
> 很多软件只给老板一堆报表，看不懂，所以用不起来。餐小助不一样，我们每天给您推送的是“大白话日报”，直接告诉您该注意什么、该做什么。而且我们有客户成功每周回访，确保您真的用得上。

**转化点**：从“报表”到“建议”，客户成功陪跑。

### 3.8 “AI会不会取代我？”

**应对**：
> AI不会取代老板，AI是帮您省掉重复 decision 的时间，让您把精力放在做好菜、管好人、照顾老客户上。您还是老板，AI是您请的数字店长。

**转化点**：AI是助手，增强老板能力。

## 4. 10分钟DEMO脚本

### 4.1 DEMO前准备

- 提前录入该门店近7天模拟数据或真实数据。
- 准备好小程序首页、客户详情页、采购单确认页。
- 准备1-2个该门店典型场景（如差评、流失客户、高损耗食材）。

### 4.2 开场（1分钟）

> 销售：王老板，我用您店的数据给您演示。您不用操作，看着就行。整个过程大概10分钟，我会带您看五个场景：经营日报、客户洞察、菜品分析、采购预测、评价管理。

### 4.3 场景一：经营日报（2分钟）

**操作**：打开微信小程序首页，点击AI日报入口。

**讲解**：
> 您看，这是今天早上8点自动推送给您的经营日报。昨天营收3680元，真实利润1120元，利润率30.4%。这里标红了两个异常：退单率6.2%，绿叶菜损耗13%。系统还建议您今天下雨，外卖单可能多15%，提前备好打包盒。

**价值点**：不用手动对账，异常一目了然。

### 4.4 场景二：客户洞察（2分钟）

**操作**：点击“客户资产”宫格，进入客户列表，点击一个流失风险客户。

**讲解**：
> 这位张先生，30天没来了，以前每个月消费两三次，客单价68块。系统给他打了“高价值客户”“流失风险”标签，建议发一张满50减5元的券，预计召回率65%。您点一下“一键发券”，券就通过微信发给他了。

**价值点**：把平台客户变成自己的老客户，自动召回。

### 4.5 场景三：菜品分析（2分钟）

**操作**：点击“菜品盈利”宫格，展示四象限图。

**讲解**：
> 这是您店里所有菜品的四象限。右上角是明星菜，又赚钱又畅销；左下角是淘汰菜，卖得少还不赚钱。您看这道“红烧茄子”，销量低、毛利也低，系统建议下架或者改配方。再看这道“酸菜鱼”，很多人点，系统建议您把它往前排，预计销量还能涨15%。

**价值点**：菜单优化直接提升利润。

### 4.6 场景四：采购预测（2分钟）

**操作**：点击“采购单”宫格，进入采购单确认页。

**讲解**：
> 这是明天要买的菜。系统根据过去90天销量、今天天气，预测明天需要14公斤鱼片、8公斤上海青。每个食材后面都有置信度， confidence低的您重点核对。您点确认，就能导出PDF发给供应商，或者直接推给员工端。

**价值点**：每天进货有依据，减少损耗和缺货。

### 4.7 场景五：评价管理（1分钟）

**操作**：点击“评价口碑”宫格，展示差评。

**讲解**：
> 这是昨天美团一条差评，系统已经用AI分析出原因是“配送慢”，并自动生成了一条回复草稿。您点一下就能复制到美团回复，不用自己绞尽脑汁写。

**价值点**：差评及时回，维护平台权重。

### 4.8 DEMO收尾（1分钟）

> 销售：王老板，您看，这五个场景就是您每天最花时间的五件事。用我们工具，每天10分钟就能看完。您看您是先用基础版试试，还是直接上专业版？
