# 资料启用与批量导入验收

日期：2026-10-27。

## 实现

- 新增 `POST /api/v2/agent/knowledge/:id/activate`，复用登录、门店及 `settings` 权限校验。在事务内检查同名版本生效期与每店 50 份启用上限，重复启用为幂等操作。
- PC 资料列表为停用版本提供“启用”，恢复原资料，不生成副本。检索仍按门店和生效日期筛选；有效向量可复用。
- 文件选择支持多选，每批最多 20 个 UTF-8 `.md` / `.txt` 文件，每份最多 200 KB、正文 20～60000 字。每份可编辑名称、分类、版本、来源、日期和正文。
- 文件逐份导入，逐份反馈成功或失败；部分失败可修改后重试，成功项跳过。切换门店不继续提交原列表。
- 资料管理弹窗改为固定标题及页签、内容区滚动，避免批量列表出现内外双重滚动。

## 验证

- 后端构建、前端构建及类型检查通过。
- `backend`: `npm run verify:knowledge`，覆盖启用恢复检索、权限、门店隔离、幂等、版本冲突回滚、50 份上限及原有引用链路。
- `backend`: `npm run verify:knowledge:hybrid`，11 项通过，含重新启用后复用有效向量。
- `front-pc`: `npm run verify:knowledge-import`，覆盖多文件解析、编码与大小限制、逐项错误、部分成功、修改重试、成功项去重及切店停止。
- 实际页面：在隔离模拟门店中停用“刘姐时蔬报价与缺货替换说明”，确认出现“启用”，点击后恢复“使用中”。一次选择两份隔离验收文件，导入后均显示成功，刷新后可在列表查看两份独立资料。
